# Valutix Connect — Android releases

Публичный канал обновлений для sideloaded APK.

Приложение проверяет:

https://raw.githubusercontent.com/valutix/connect-releases/main/android/latest.json

APK прикладывайте к [GitHub Releases](https://github.com/valutix/connect-releases/releases), не коммитьте бинарники в `main`.
